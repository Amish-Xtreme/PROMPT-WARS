# MedLens — AI-Powered Clinical Information Intelligence

MedLens is an AI-powered healthcare application designed to transform fragmented medical information into a structured, understandable, traceable, and reviewable patient record.

## 📌 Core Features

* **Patient Information Intake:** Captures symptoms, medical conditions, allergies, and current medications.
* **Medical Report Processing:** Automatically extracts lab test names, numeric values, units, reference ranges, and observation dates.
* **Reference-Range Awareness:** Automatically flags lab values as **LOW**, **NORMAL**, or **HIGH** based strictly on ranges provided in source reports (without inventing normal bounds).
* **Source & Provenance Tracking:** Clearly distinguishes between user-provided information and AI-extracted data.
* **Safe AI Summaries:** Generates clear, patient-friendly summaries without providing clinical diagnoses or medical treatment recommendations.

---

## 🛠️ Key Capabilities

* Inconsistency and conflict detection across intake and lab data
* Human verification and editing workflow
* Structured schema output for reviewable electronic records
* Built-in safety guardrails adhering to Responsible AI practices
